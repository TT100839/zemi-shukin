# ゼミ集金ノート

ゼミの懇親会の幹事向けツールです。会費の計算、集金の照合、当日名簿、連絡文づくり、会計Excelの出力までを1つのページで行えます。

公開ページ：`https://<GitHubのユーザー名>.github.io/zemi-shukin-note/`

## できること

| タブ | 内容 |
|---|---|
| ホーム | 集金の進み具合（瓶のイラスト・内訳バー）、「次にやること」、メンバーごとの状況 |
| 集金 | 入金の記録と照合（番号チェック・重複チェック・お釣りの返金チェック） |
| 名簿 | 当日の出席・お酒のチェック、未入金の人の現金受け取り記録 |
| 連絡 | 会費の連絡・未入金の催促・当日の案内を自動で作ってコピー |
| 設定 | イベント情報、支払い先、お店の項目、会費の自動計算、メンバー、引き継ぎファイル |

## はじめて使う人

1. 公開ページを開く（スマホならブラウザの共有ボタンから「ホーム画面に追加」）
2. 前の幹事から **引き継ぎファイル（.json）** をもらう
3. 「設定」タブ →「引き継ぎファイルを読み込む」で読み込む
4. 「設定」→「新しいイベントを作る」で次の会を作り、日付・お店・金額を直して「この計算で会費を入れる」→「設定を保存」
5. あとはホームの「次にやること」を上から押していけばOK

## 引き継ぐとき

「設定」→「引き継ぎファイルを書き出す」で出た .json ファイルを、次の幹事に渡してください（Teamsのチャットなど）。

## 大事な注意

- **データはこのページを開いた端末のブラウザに保存されます。** サーバーには送られません。
  - 別の端末で続きをするとき、ブラウザのデータを消す前は、必ず引き継ぎファイルを書き出してください。
- 引き継ぎファイルには振込先や入金記録が入ります。**GitHubには上げず**、幹事どうしで直接渡してください。
- このリポジトリ（index.html）には、個人の名前や口座などのデータは入っていません。
- 証拠の写真は claude.ai 版でのみ使えます（引き継ぎファイルにも含みません）。

## 会計ルール（山崎ゼミ）

- 学生の会費＝コース料金−先生の補助、先生の会費は残りを1,000円単位で切り上げ
- 前回残高を持っている人は、会費に残高を足して渡す
- 余りは次回に繰り越し、会計Excelとエビデンスを会計チャネルに報告

## GitHub Pages で公開する手順

1. GitHubで新しいリポジトリ `zemi-shukin-note` を作る（Public）
2. このフォルダの `index.html` `README.md` `.nojekyll` をアップロード
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/zemi-shukin-note/` で開けます
